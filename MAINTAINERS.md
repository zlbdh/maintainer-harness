# Maintainers

Maintainer Harness is currently maintained by:

- `zlbdh`

## Maintainer Responsibilities

- Keep the repository generic and safe for public use.
- Review changes to validation scripts, templates, schemas, and publication checks.
- Keep private product repositories, generated worktrees, credentials, logs, and customer data out of the public repository.
- Review security-sensitive changes with extra care, especially MCP, automation, and write-scope behavior.

## Becoming A Maintainer

The project is early-stage. Maintainer onboarding should happen after sustained, high-quality contributions to:

- documentation
- validation scripts
- maintainer workflow examples
- issue triage
- security and public hygiene improvements
