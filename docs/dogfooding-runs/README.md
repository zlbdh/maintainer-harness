# Dogfooding Runs

This directory records public Maintainer Harness dogfooding runs. Each run should
show what Codex or agent assistance changed, which public artifacts were
produced, which validation gates passed, and what remains unproven.

The goal is evidence, not hype. A run is useful when another maintainer can see
the workflow, inspect the resulting files, and decide whether the harness made
agent-assisted work easier to review.
