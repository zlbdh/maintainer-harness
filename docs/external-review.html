Clean checkout

Run the synthetic demo.

The demo does not need private repositories, credentials, generated worktrees, or production logs. Use Windows PowerShell or PowerShell 7 on macOS/Linux. The command prints issue #6 and writes a local Markdown report plus a JSON summary with a copy-ready public comment block. 

git clone https://github.com/zlbdh/maintainer-harness.git
cd maintainer-harness
.\scripts\checks\run-review-demo.ps1

# macOS/Linux with PowerShell 7
pwsh ./scripts/checks/run-review-demo.ps1
