Clean checkout

Run the synthetic demo.

The demo does not need private repositories, credentials, generated worktrees, or production logs. Use Windows PowerShell or PowerShell 7 on macOS/Linux. The command prints issue #6 and writes a local Markdown report plus a JSON summary with a copy-ready public comment block. If Git, PowerShell, execution policy, or path setup blocks the run, use the first-run troubleshooting guide before posting the failure. 

# Cloud path
https://codespaces.new/zlbdh/maintainer-harness?quickstart=1
pwsh ./scripts/checks/run-review-demo.ps1

# Local path
git clone https://github.com/zlbdh/maintainer-harness.git
cd maintainer-harness
.\scripts\checks\run-review-demo.ps1

# macOS/Linux with PowerShell 7
pwsh ./scripts/checks/run-review-demo.ps1

# Optional: copy the issue #6 block and open the comment target without posting
.\scripts\checks\run-review-demo.ps1 -CopyCommentToClipboard -OpenCommentTarget
pwsh ./scripts/checks/run-review-demo.ps1 -CopyCommentToClipboard -OpenCommentTarget

# Optional Chinese issue #6 block
.\scripts\checks\run-review-demo.ps1 -CommentLanguage zh -CopyCommentToClipboard -OpenCommentTarget
pwsh ./scripts/checks/run-review-demo.ps1 -CommentLanguage zh -CopyCommentToClipboard -OpenCommentTarget
