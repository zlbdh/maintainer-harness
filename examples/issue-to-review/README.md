# Issue To Review Packet Example

This synthetic example starts from a GitHub issue and turns it into a scoped change packet that a maintainer could use before pull request review.

It is repository-agnostic by design. The issue, repository names, branches, worker output, and reviewer evidence are examples only.

Validate this sample from the repository root:

```powershell
.\scripts\checks\validate-change.ps1 -Path examples\issue-to-review
```
