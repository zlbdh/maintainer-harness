# Brief

Change id: `CHG-2026-0002-issue-to-review-packet`

## Source Issue

- Provider: GitHub
- Repository: `example/maintainer-tool`
- Issue: `#42`
- Title: `Document the validation evidence required before PR review`

## Problem

A maintainer wants to let an agent draft documentation, but the reviewer needs the work converted from an issue into explicit scope, expected evidence, and acceptance criteria before any pull request is opened.

## Goal

Create a bounded change packet that shows how an issue becomes a reviewable worker task and reviewer acceptance record.

## Non-Goals

- Do not connect to a real GitHub repository.
- Do not open a pull request.
- Do not include private repository names, local paths, credentials, product screenshots, or customer data.
