# Release Workflow Packet Example

This synthetic example shows how Maintainer Harness turns verified worker output into release notes and postmortem-ready evidence.

It is designed for maintainers who need to distinguish passed checks from skipped or environment-limited checks before making a release decision.

Validate this sample from the repository root:

```powershell
.\scripts\checks\validate-change.ps1 -Path examples\release-workflow
```
