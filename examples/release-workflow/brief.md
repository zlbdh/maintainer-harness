# Brief

Change id: `CHG-2026-0003-release-evidence`

## Problem

Maintainers need a release example that keeps validation evidence, skipped checks, rollback steps, and postmortem follow-up in files instead of chat history.

## Goal

Create a synthetic release workflow packet that demonstrates how verified worker output becomes release-ready evidence.

## Non-Goals

- Do not create a real tag.
- Do not publish a real release.
- Do not claim product repository tests passed when no product repository is connected.
- Do not include private paths, private endpoints, credentials, production logs, or customer data.
